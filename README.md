# geodynamics_test

Odoo addons repository for the **Geodynamics** module by
[Data Forge](https://www.data-forge.be) — the integration between Odoo and the
IntelliTracer API (GPS tracking, fleet management, employee planning, time
registration and Checkinatwork / CIAW).

## Contents

| Path           | Description                                              |
| -------------- | -------------------------------------------------------- |
| `geodynamics/` | The Odoo module. See its own `README.md` and `FUNCTIONALITIES.md`. |

## Installation

Add the root of this repository to your Odoo `addons_path`, then install the
**Geodynamics** app from Apps.
